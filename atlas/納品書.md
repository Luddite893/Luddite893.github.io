## 3　検収基準への対応

### 基準 1　二冊を並べたとき、明確に別の時代・別の目的の本に見えること

これが本件の隠れた主題だと理解しています。対比を**六つの層すべて**で作りました。

| | 『暁の砕き手』 | 『タムリエル勢力誌』 |
|---|---|---|
| 判型 | A5 148×210 | A4 210×297 |
| 書体 | しっぽり明朝（活版起点・字面が湿る） | Noto Serif JP（癖のない現代明朝） |
| 地色 | 手漉きの羊皮紙。葉ごとに違う | 均一な淡クリーム。全 140 頁同一 |
| 版面 | 一段組。行が揺れる | 六列グリッド。全頁で骨格が動かない |
| 図版 | 細密画 6 点。顔を描かない | 銅版画調 441 点。すべて同一の調子表に従う |
| 損傷 | 掻き取り・虫損・水損・焼け | **一切なし**。汚れも褪色もない |
| 人称 | 一人称（ブラ） | 三人称。編者は「本書」としか名乗らない |
| 感情 | 記述の中心 | **一語も書かない**（序でその方針を明示） |
| 関係の書き方 | 情の流れとして本文に書く | **図式のみ。散文を禁止** |
| 時制 | 現在に立ち会う | 二百年後から見下ろす |

同じ世界を扱いながら、**紙を触った瞬間に別の本だと分かる**状態になっています。

### 基準 2　小口を見て分類が判別できるか

判別できます。**色と位置の二重符号**にしました。

各頁の小口側の縁に、分類色の帯（幅 6mm・丈 26mm）を刷ります。
色だけで分けると、閉じたとき隣り合う分類が混ざって見えます。
そこで帯の**天地の位置も分類ごとに固定**しました（I は天寄り、VII は地寄り、七段）。
本を閉じると小口に七本の縞が現れ、色が判別できない条件でも位置で引けます。
表紙にも同じ順・同じ幅の七本の帯を並べてあるので、
閉じたときの縞は表紙の縞の続きに見えます。

### 基準 3　49 の紋章が同一の設計思想で描かれているか

**一点ずつ描かないこと**で担保しました。49 点を手で描けば、必ず 49 通りの思想が混ざります。
手の癖は途中で変わり、後半に描いたものほど巧くなる。それが「ぶれ」の正体です。

代わりに共有の語彙（獣頭・手・眼・刃・山・環・星ほか 40 種）を定め、
各組織をその組み合わせとして記述しました。狼と熊と鷲は同じ「獣頭」の比率から出ます。
闇の一党・シルバーハンド・ステンダールの守人の手は、同じ「手」から出ます。

規約は次のとおりで、49 点すべてが従います。

- 外形　円。二重罫 外 r=56／内 r=50.5。**不変**
- 座標　120 × 120、中心 (60,60)、図象領域 r ≦ 41
- 構成　塗りのみ。線を引かない（単色シルエットで成立させるため）
- 最小寸法　8mm で判別できること（120 単位系で 2.6 未満の細部を作らない）
- 面積率　**18〜34%**

面積率は目視ではなく**実測で揃えました**。各紋章を実際に描画して画素を数え、
目標 26% との比から拡縮係数 k を解いて（面積は k² に比例）較正しています。
較正前は 3.7%〜68.6% とばらついていたものが、**現在は 26.7%〜29.2%（平均 28.4%）**、
規定範囲を外れる点は 0 です。

拡縮だけでは救えない図象——係数が上下限に張り付いた点——は、
機械が名指しするので、その 6 点は図象そのものを描き直しました
（ウィンターホールド大学・ペントゥス・オクラトゥス・サイジック会・アリキール・
サマーセットの影・グレンモリルの魔女）。
線が細すぎて拡大しても面積が稼げないもの、逆に面が大きすぎて縮小すると
図象が読めなくなるものの二種で、いずれも語彙の組み合わせを変えて解いています。
**同一の設計思想であることを、目でなく数で保証しています。**

滅亡した 3 項（アーリエルの聖堂・トリビュナル寺院・ドラゴン教団）には、
外郭を貫く打ち消しの横線を与えました。図象側は削っていません。
滅んだのは組織であって、その徽章の意匠ではないからです。

### 基準 4　図版 441 点が同一画風で揃っているか

揃っています。詳細は 4 節（14-2／14-3 への回答）に記します。
要点は、**調子（濃さ）を線の関数として一度だけ定義し、全図版がその一つの表を参照する**こと。
表の値は**刷り上がりのミリ**で持っているので、
紋章 22mm・人物 18mm・小カット 25mm・主図版 174mm と大きさが違っても、
**彫りの目は等しくなります**。銅版画の目が版の大小によらず一定なのは、彫師の手が一定だからです。

### 基準 5　関係欄から実用的に引けるか

引けます。関係欄は**散文を一語も使わず図式のみ**とし、
節点（紋章）そのものが PDF 内部リンクになっています。
関係図の相手の紋章を押せば、その組織の項へ飛びます（本編の関係欄だけで 142 箇所＝関係 71 件の両端）。
分類扉の関係図 226・人物索引 149・年表 74・全体相関図 59・目次 49・門戸一覧 49・分布図 14 を合わせ、
**合計 762 箇所**です。

関係欄の丈は関係の数で決めています。二件の組織に六件ぶんの箱を与えると、
空白が「何かが抜けている」という誤った合図になるためです。
さらに、組版後に版面の余りを**実測して**関係図の丈へ戻しています
（`src/fit.mjs`。三巡で収束）。節点が増えるのではなく大きくなるだけなので、
空欄が欠落を示すという誤読は生じません。

## 4　仕様書 14 の照会への回答

### 14-2　図版 150 点超の人物図版を、統一画風で揃える手法

**部品の組み合わせとして定義しました。** 149 点を一点ずつ描けば必ず崩れます。

胸像は次の四つの層の組み合わせだけで構成されます。

| 層 | 種類 |
|---|---|
| 頭蓋 | human / nord / elf / orc / khajiit / argonian（6） |
| 被り物 | none / hood / helm / horned / circlet / cowl（6） |
| 髪 | none / long / short / topknot / braid（5） |
| 装い | mail / plate / robe / fur / leather / bare（6） |

理論上 1,080 通り。149 点はそこから選んだ組み合わせにすぎません。
肩の傾き・首の長さ・眼窩の位置・光源（左上）は全点で共通です。

**顔は描いていません。** 人物図版は肖像ではなく、
記録に残る特徴——種族・被り物・装い——のみを図取りしたものです。
凡例にその旨を明記しました。実在しない人物の顔を確定させることは、
学術図鑑がやってはいけないことです。眼窩は二本の曲線で示すのみとしています
（初期案では横一本の帯にしていましたが、全員が目隠しをしているように見えたため改めました）。

### 14-3　銅版画調の実現方法（手描き／版画的処理／その他）

**「その他」を採りました。**

- **手描き**は 441 点で必ず崩れます。前半と後半で手が変わるからです。
- **版画的処理**（写真をハーフトーン化する類）は元画像の階調に依存します。本件には元画像がありません。

採ったのは第三の道——**調子を線の関数として定義する**方法です。
図版は「形」と「その各部の濃さ」だけを持ち、線は生成器が引きます。
濃さ 0.0〜1.0 から線への写像が**一つしかない**ので、
441 点が同じ彫師の手で彫られたものになります。

線そのものの作り方も規約に従います。ビュラン（彫刻刀）は V 字の溝を彫り、
押し込むほど溝が深く広くなり、抜くときに細くなる。だから一本の線が
**中央で太り、両端で消える**。等幅の線を並べても銅版画には見えません。
本エンジンは線を「棒」ではなく「木の葉形」として置いています。

濃さの段階も共有します。

| 濃さ | 技法 |
|---|---|
| 薄い | 線を疎に、細く |
| 中間 | 線を密に、太く |
| 濃い | 二番手を 54° 斜交（cross-hatch） |
| 最濃 | 三番手を 108° に入れ、その下に地を敷く |

技法が切り替わる閾値を全図版で共有するので、濃さの見え方が揃います。
真っ黒な面は作りません。銅版画に真っ黒な面は無いからです。

**二色刷りの扱い。** 色版（分類色の面）は必ず墨版（線）の下に敷き、
**線には色を付けません**。線に色を乗せた瞬間、二色刷りではなく
「着色されたイラスト」になります。ここは全点で守っています。

### 14-4　49 ノード相関図の可読性を保つための設計案

**四つの手を打ちました。**

1. **位置に意味を持たせる。** 節点は本編の並び順（分類 I の先頭から時計回り）に置きます。
   円環上の位置が頁順に対応するので、図から本編を引けます。外周には分類の帯を敷きます。
2. **弦は敵対だけにする。** 71 件すべてを弦として内側に引くと、円の中が塗り潰されます。
   敵対（29 件）だけを弦とし、それ以外の関係は**外周の弧**で示しました。
   結果として、弦の集まる位置がそのまま「州の対立の焦点」になります。
3. **次数を刻みで外周に出す。** 各節点の外側に、敵対関係の本数だけ短い刻みを打ちます。
   線を数えなくても四面楚歌の組織が分かります。
4. **見開きに跨がせない。** 円環図を見開きで割る案は捨てました。
   弦の交わる中心がノドに落ち、綴じで一〇ミリ持っていかれる位置に、
   この図のいちばん読ませたい部分が来てしまいます。
   図は右頁に一枚で置き、**左頁を「読むための装置」に充てました**
   （分類間の関係数を示す 7×7 の表、敵対の集まる組織の順位）。
   円環図では数えないと判らない偏り——たとえば分類 V「宗教・信仰」の行がほとんど空であること——が、
   表にすると一目で出ます。

各項の関係欄は同じ記法の自我図とし、記号の凡例は巻頭に一度だけ載せています。

### 14-1・14-5 について

お手元の仕様書 14-1 および 14-5 は、こちらの控えに**項番のみが残り、文言が残っていません**。
該当すると思われる二つの論点について、以下に回答いたします。
ご照会の趣旨と異なる場合はお知らせください。追って書き直します。

**（一）分類色と二色刷りが成立するか。**
成立します。七色（鈍い金・深い赤・錆色・濃緑・藍・紫黒・土色）はいずれも
彩度を抑えた顔料色で、墨と重ねても濁りません。分類色が乗るのは
小口の帯・柱の罫・紋章の枠・見出しの罫・引用の上罫・図式の節点の輪郭のみで、
**線画そのものには一切乗せていません**。したがって刷版は常に二版で足ります。
色の見分けがつかない条件でも、小口の帯は天地の位置で、分類は記号 I〜VII で引けます。

**（二）増補と改版の運用。**
本書は一点ずつ手で組んだものではなく、**データから組み上げています**。
組織を一項足す場合、`src/factions.mjs` に紋章の記述を、`src/records.mjs` に本文を、
`src/relations.mjs` に関係を書き加えれば、目次・索引・年表の参照・分類扉の一覧・
全体相関図・分布図・しおり・内部リンク・頁数がすべて自動で追随します。
頁の偶奇（見開きが割れないこと）は組み上げ時に機械検査され、
崩れていれば出力を止めます。巻末に四頁の追記欄を置いたのは、
この運用を読者の側にも開いておくためです。

## 5　仕様書からの変更点（ご指示・ご報告）

### 5-1　「加入可能ギルド」→「門戸」（ご指示により改称）

原仕様の「加入可能ギルド」は、読者ではなく**操作者**から見た区分でした。
他の六分類が血統・国籍・信仰・地縁という**世界の内側の基準**で括られているのに対し、
この一項目だけ視座が違います。学者が編んだ本の目次に、この行はあってはなりません。

分類名は **I「職能結社」** と改めました。
他の六分類が「生まれつき決まる」のに対し、この群だけが
「入門と修練によって成員となる」——その一点で括り直しています。

あわせて、各項の標識としての「加入可否」を **「門戸」** と改めました。
値は 開く／試練による／閉ざす／血統による の四段です。
最後の「血統による」は加入の可否ではなく、
**加入という手続き自体を持たない**ことを示します。
可否を問うこと自体が成り立たない集団があるので、この区別を立てました。
凡例にその旨を明記しています。

### 5-2　頁数（ご指示により上限撤廃）

仕様書の p128 という目安に対し、**140 頁**としました。
増えたぶんは、分類扉見開き 7 組（14 頁）と、年表・目次・索引の拡充です。
分類扉の右頁には、その分類の関係の行き先を示す二部グラフを新たに置きました。
上段がその分類の組織、下段が相手で、
**分類の内側で閉じているか外へ出ているかが線の形だけで判ります。**

## 6　レイアウトデータについて

仕様書 12 の「InDesign 相当のレイアウトデータ」について。
本件の組版は InDesign ではなく HTML/CSS で行っているため、`.indd` は存在しません。
代わりに、InDesign の**ドキュメント設定・マスターページ・段落スタイル・
オブジェクトスタイル**に対応する数値をすべて `out/版面データ.json` に出しました。
これを見れば InDesign 上に同じ版面を起こせます。

主要な数値のみ再掲します。

- 判型 A4 縦 210 × 297。天 19／地 26／ノド 19／小口 17。版面 174 × 252
- 六列グリッド。段間 4、一段 25.667。**六は 1／2／3／6 に割れる**ので、
  全幅・半幅・三分割・六分割が同じ溝で成立します（四列だと三分割が作れず、八列だと三分割が半端になります）
- ベースライン 45 行、行送り 5.6。図版の高さも行送りの整数倍に丸めています
- 本文 3.35mm／行送り 5.6mm／両端揃え／禁則あり
- 分類色 7 色、小口の帯の位置 7 段、彫りの調子表（刷り上がりミリ）

**検索性について一点。** Chromium は字形を共有する符号位置が複数あると、
逆引きでどれを書くか選べません。結果として ToUnicode に部首や旧字形の符号位置が入り、
見た目は正しいのに「戸」で検索して「戶」は引っかからない、という状態になります。
本件では ToUnicode を 11 本書き直してこれを潰しました。
直すべき字は推測ではなく、**PDF から抽出した字のうち組版の元原稿に無いもの**を
機械で洗い出して特定しています。現在、その差分は **0 字**です。

版面からの溢れも全 140 頁で機械検査しており、現在 0 頁です。
