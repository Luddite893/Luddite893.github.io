## 3　第二版で作り直した四点

### 3-1　本文（改訂一）

58 項すべてを、同胞団の見本を基準として書き下ろしました。

| 節 | 規定 | 実績（平均） |
|---|---|---|
| 概要 | 200–250 字 | 220 |
| 沿革 | 400–600 字 | 494 |
| 内情 | 300–500 字 | 400 |
| 評判 | 200–300 字 | 259 |
| 記録の欠落 | 80–150 字 | 99 |

**総計 85,080 字。規定を外れる節は 0 です**（`node src/check-records2.mjs`）。

三つの規約を全項で守っています。

- **「評判」は矛盾を解かずに並べる。** 同じ組織が、農村の請願書では治安の代替として、
  帝国軍の駐屯報告では徴募の妨げとして記録されます。どちらが正しいかは書きません。
  出典を添えて両方を刷り、判断を読者に残します。
- **「記録の欠落」は三種類しか書かない。** 閲覧できなかった／失われた／そもそも作られなかった。
  「〜と思われる」は一度も使っていません。欠落の理由を推測することは、記録ではなく創作です。
- **観察者を名指しする。** 文字を持たない集団・外部と接触しない集団については、
  内情を外からの観察で書くほかありません。その場合、**誰が観察したかを各欄に書き添えます**。
  書き添えないと、観察が事実の顔をします。

### 3-2　相関図（改訂二）

ご指摘のとおり、初版の相関図は読めていませんでした。原因は四つあります。

| | 何が起きていたか |
|---|---|
| 一 | 節点が紋章だけだった。紋章は 25mm で判別できるよう設計した図象で、7mm では何の組織か分からない |
| 二 | 関係が線の種類で表されていた。実線・二重線・破線・点線の四つを覚えないと一本も読めない |
| 三 | 四十九点を一枚に詰めた。弦が中央で束になり、どの線がどこへ行くのか追えない |
| 四 | 位置に分類の意味を持たせすぎた。同じ出来事に関わる組織が円の反対側に離れる |

ご提示いただいたゲーム・オブ・スローンズの相関図が読みやすい理由は、線の引き方ではありません。
**札の中で人物が説明されていること**です。顔・名・肩書が札の中にあるので、凡例に戻らずに済みます。

そこで節点を**札**に改めました。

```
┌──────────────────────────┐
│ ▌ [紋章]  帝国軍                        │  ← 組織名
│ ▌         帝国の常備軍                  │  ← 肩書（49 項ぶん書き下ろし）
│ ▌                       ソリチュード    │  ← 所在
│ ├──────────────────────┤
│ ▌ 敵対　ストームクローク               │  ← 関係の行。ここから線が出る
│ ▌ 従属　サルモール                     │
└──────────────────────────┘
```

**途中で一度、方針を改めています。** はじめは線の中ほどに語の小札を置いていました。
これは破綻します。一枚の札から線が n 本出るとき、語も n 個要る。ところが札の縁は 13mm しかない。
語の小札は 4mm 強あるので、三本を超えたところで必ず重なります。
そこで語を線から降ろし、**札の中の「関係の行」として持たせました**。
結果として、**線の上には文字が一つもありません**。

配線は直交でのみ引きます。斜めに引くと、二本が交差したときにどちらがどちらか分からなくなります。
直交なら交差は必ず直角になり、目で追えます。経路は最大で五点（札の縁 → 溝の通り道 → 廊下 → 溝の通り道 → 相手の行）。
通り道と廊下は、区間の重なる線どうしで必ず別のものを割り当てます。

一枚あたり七〜十枚に絞り、**三十四枚**に分けました。

| | 枚数 | 内容 |
|---|---|---|
| 主題別 | 9 | 内戦／信仰の禁圧／竜の帰還／血と呪い／盗みと負債／記録と知／容認されざる祭祀／辺境と部族／**九領の帰属** |
| 分類別 | 25 | 八分類。札の高さが関係の数で決まるため、**相手ではなく成員のほうで割った** |

成員で割ったので、**どの組織も「自分の関係が全部見える一枚」を必ず持ちます**。

主題別の八枚は、分類ではなく「何が起きているか」で束ねた図です。
たとえば「血と呪い」の一枚には、同胞団・グレンモリルの魔女・シルバーハンド・シルバー・ブラッド家が並びます。
分類は I・VI・III・IV とばらばらですが、**与える者・負う者・狩る者・銀を売る者**が
一本の線でつながっているのが見えます。分類は「その組織が何であるか」の区分であって、
「何が起きているか」の区分ではありません。

**相関図索引（46–47 頁）を新設しました。** 三十四枚に割った代償です。
五十八項が三十四枚のどこに出るかを示し、●を付した一枚には、その組織の関係が漏れなく載っています。

**各項の四頁目も同じ文法に揃えました。** 図をやめ、札の中と同じ「語・紋章・相手の名・註」の行にしています。
版面の高さが 44mm しかなく、図にすると札を三枚しか置けなかったためです。

### 3-3　年表への流し込み

第二版の沿革は 289 段落あり、各段落が年の札を持っています（`4E 175` のような形）。
これを年表へ手で書き写せば、必ずどちらかが古くなります。

**そこで札のほうを機械に読ませ、年表の行に項を結びつけました。**
沿革にその年の段落があれば、その項は必ずその年の欄に出ます。手で書き写していないので、
本文を直せば年表も直ります。

年の札は四通りあり、扱いを分けています。

| 形 | 扱い |
|---|---|
| `4E 175` | その年の行に結ぶ |
| `4E 175以後` | 起点の年の行に結ぶ |
| `4E 176–201` | 起点の年の行に結ぶ |
| `4E 17x`／`3E 末`／`1E`／`不明` | 年を特定できない。紀ごとの欄にまとめる |

沿革にあって年表に無い年が六つあったので、行を新設しました
（2E 582 リーチの帝国編入／2E 758 ウィンターホールドの大崩壊／3E 240 影の印の最古の用例／
4E 177 ファルクリース領の帰属表明／4E 197 失踪の模倣判定／
4E 200 守人本部の焼失とドーンガードの砦の修復）。
突き合わせは `node src/check-chron.mjs` が行い、現在**齟齬 0** です。

**第四紀二〇一年の行だけは、番号を裏返して刷っています。** 記述の現在なので、
ほとんどの項が何かを持ちます。全項の番号を刷っても索引になりません。
**持たない側**——その年の記述を持たない項——を出したほうが情報になります。

### 3-4　出典索引の新設

各項の「評判」は、必ず出典を伴う引用で組んであります。232 件あります。
これまで、その一覧はどこにもありませんでした。
序に挙げた底本は編纂の骨組であって、引用一件ごとの出どころではないからです。

一覧にすると、序では見えなかったことが二つ出ます。

- **本書がどの記録に寄りかかっているか。** ホワイトラン領と帝国軍が最も多く、
  異なり 151 点のうち、この二つが突出しています。
- **同じ一点が二つ以上の項に引かれている件数があること。**
  これは、二つの組織が同じ一人の目から記述されているということです。
  立場の違いが記述の違いとして現れているのか、記録者ひとりの見方が二つの項に及んでいるのかは、
  一覧では区別できません。区別が必要な読者は、当該の項を並べて読むほかありません。
  その旨を頁に明記しました。

## 4　地図の作り直し

ご指摘の「文字が被っている」点について。原因は仕組みのほうでした。
札を「点の右へ一定量」で置いていたので、点が寄れば札も寄り、
図の縁に近い点では札が図の外へ出ていました。

置き場を決める仕事を一つの関数にまとめ直しています。

- **十六方位・四段の環**を順に試し、すでに置いた札・打った点・図の縁、
  そして州の輪郭の内側かどうかを見て、最初に通った位置を採る
- どれも通らなければ、**破れの量がいちばん小さい**位置を採る
- それでも収まらない札だけ、字を一段ずつ詰めて置き直す
  （「破れ」と「点から離れていること」は別に数えます。混ぜると、
  ただ譲っただけの札まで字を詰められて、領の名と地名の格が並んでしまいます）
- 点から離れた札は、細い**引出線**で点に戻す

あわせて三つ直しました。

- **同じ地点に来る名をまとめた。** ジョラーヴァスクルはホワイトランの中にあります。
  点を二つ打てば札も二つ要り、必ず重なります。2.5 単位以内は一点にまとめ、名を積みます。
- **ハイフロスガーの位置を正した。** 初版はホワイトランと同じ点に打っていました。
  世界の喉の中腹へ移しています。
- **州外の点の札を、州の中へ入れないようにした。** ソルスセイムとモロウウィンドの札が
  輪郭の太い線の上に乗っていました。図の枠を右へ広げ、札を外へ出しています。

`node src/check-maps.mjs` が、札の重なり・図の枠外・輪郭の内外を数えます。**三図とも可**です。

図の下に余っていた版面には、図から引くべき表を入れました。
図一に**州外に本拠を置く十三項**、図二に**九つの領と領都**（領ごとの所収項つき）。
分類 VIII を立てたことで、図二の表の各行は本編の項へ直接飛ぶようになりました。

## 6　機械で検めていること

第二版では、目で拾えないものを機械に言わせる検査を六つ持っています。
**いずれも数字で出ます。**

| 検査 | 何を見るか | 現在 |
|---|---|---|
| `check-records2.mjs` | 五節の字数が規定に収まるか。関係の註が辺と一致するか | 58/58 項　規定外 0 |
| `check-fit.mjs` | 本編 232 頁の版面からの溢れ | 溢れなし |
| `check-book.mjs` | **全 316 頁**の版面からの溢れ | 溢れなし |
| `check-maps.mjs` | 地図の札の重なり・枠外・輪郭外 | 三図とも可 |
| `check-chron.mjs` | 年表と沿革の年の突き合わせ | 齟齬なし |
| `proof-relmap.mjs` | 線が札を横切らないか。札が重ならないか。版面から出ないか | 34 枚すべて可 |

このほか、組み上げ時に**頁の偶奇**（見開きが「偶数＝左」で始まること）と
**総頁が四の倍数**であることを検査し、崩れていれば出力を止めます。
一頁ずれると四十九の見開きがすべて割れるので、ここは通らないまま先へ進めません。

## 10　分類 VIII「領邦・宮廷」について（第二版・追補）

ご指示により、九つの領とその宮廷を項として加えました。

**なぜ既存の分類に入れず、分類を一つ立てたか。** 九領は他の七分類の組織が
「その上で」動いている場です。同胞団の項に「ホワイトラン領」と書いても、
その領が何であるかを引く先が本書に無い——これが初版の欠落でした。
分類 II「国家・軍事」に入れる案も検討しましたが、
分類 II は「領域と武力を有し、統治を行うか、それを争う組織」であり、
帝国軍とストームクロークが入ります。九領はその両方に**帰属を選ばされる側**であって、
争う側ではありません。同じ棚に置くと、この非対称が消えます。

**名は市の名で立て、領の名を別称に置きました。** 記録の用例が市の名で書かれているためです。
「リーチ領」で引かれる読者のために、総索引と別称の双方から辿れるようにしてあります。

**この分類に固有の事情を、本文の書き方に反映しています。**
九項は他の七分類と違い、**記録を作る側**です。市政の記録・法廷の記録・徴税の台帳は
いずれも領が付けたものであり、本書の他の項の典拠の多くがこの九つの宮廷から出ています。
したがって「記録の欠落」の意味が他の分類と違います。記録を作る側が書かなかったことは、
書けなかったのではなく**書かないことを選んだ**可能性があります。
両者を本書は区別できません。区別できないことを、各項の欠落の欄に明記しました。

**門戸が九項とも「試練による」で揃いました。** 手抜きではありません。
この州では首長の座は血によって継がれ、宮廷に加わる道——従士（セイン）の位——は
領への功によってのみ開きます。願い出て入る者はおらず、生まれで宮廷に入る者もいない。
九領がこの一点で揃っていること自体が、この州の統治の形です。分類扉に明記しました。

**主題別の相関図に一枚を加えました。** 主題九「九領の帰属」（20 頁）。
四領が帝国、四領が蜂起、一領が中立です。中央の列には、ムートと、
**帰属の言い方に留保のついた三領**を置きました。ホワイトランはいずれとも反目にとどまり、
ファルクリースは表明が一年以上遅れ、モーサルは与すると書いた同じ文書の中で
自らの選択を疑っています。

**九領のあいだの直接の線は一本だけです。** 内戦の二つの首都（ソリチュードとウィンドヘルム）の
あいだの敵対です。帰属の違いは領どうしではなく、領と両軍のあいだの線として現れます。
分類扉の「分類の内側の関係」の欄は、この事実を機械が数えて出しています。

**七分類を前提していた箇所を、分類の数から採るように直しました。**
小口の帯の位置（`(frameH - h) / (categories.length - 1)`）、
分類間の関係数の行列、目次の割り、相関図の枚数、漢数字の変換。
初版から「`'一二三四五'[n-1]`」で書かれていた箇所は、分類 II の相関図が
六枚を超えた時点で `undefined枚` と刷られていました。汎用の漢数字関数に置き換えています。
