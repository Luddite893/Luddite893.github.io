# 使用フォント一覧

『タムリエル勢力誌』／閲覧用 PDF・印刷用 PDF

書体は**二種のみ**。学術書の体裁は、書体の数ではなく格の一貫で作る。
本書で格を作っているのはウェイトと級数であって、書体の切り替えではない。

いずれも **SIL Open Font License 1.1**。PDF への埋め込み、商用利用、
オンデマンド製本のいずれにも制限はかからない。追加のライセンス費用は生じない。

すべて PDF に**サブセット埋め込み済**。閲覧環境に依存しない。
出力 PDF に現れるフォントは以下の 4 本のみで、代替書体・Type3 は 0 本である
（`src/finish.py` の検品で毎回機械確認している）。

---

## 和文 — Noto Serif JP

| | |
|---|---|
| 使用ウェイト | Regular 400 ／ Medium 500 ／ SemiBold 600 |
| 用途 | 本文、概要、目的、図版説明、表組、索引、見出し、扉、表紙 |
| 権利表示 | Copyright 2014–2021 Adobe (http://www.adobe.com/) |
| 配布元 | Google Fonts ／ https://github.com/notofonts/noto-cjk |
| ライセンス | SIL OFL 1.1 |

**採用理由。** 本書は「後世の学者が編纂した学術図鑑」であり、
姉妹編『暁の砕き手』のような**手の痕跡を残してはならない**。
Noto Serif JP は活版の癖を持たない現代的な明朝で、字面が均質である。
姉妹編で採ったしっぽり明朝が「はじめから濁っている」書体だったのに対し、
こちらは**はじめから乾いている**。二冊を並べたときの隔たりの半分は、
この選択で作られている。

ウェイトの割り当ては次のとおり。見出しに別書体を持ち込まないための設計である。

| ウェイト | 用途 |
|---|---|
| Regular 400 | 本文・概要・図版説明・表組の値・索引 |
| Medium 500 | 分類標識の値、拠点名、人物名の一部 |
| SemiBold 600 | 大見出し、項の名称、小見出し、柱の分類名 |

## 欧字 — EB Garamond

| | |
|---|---|
| 使用ウェイト | Regular 400 のみ |
| 用途 | 項番号、ノンブル、欧字併記名、紀年、表組の数値、分類記号 I〜VII |
| 権利表示 | Copyright 2017 The EB Garamond Project Authors |
| 配布元 | Google Fonts ／ https://github.com/octaviopardo/EBGaramond12 |
| ライセンス | SIL OFL 1.1 |

**採用理由。** 仕様書 7 は各項に「学名風の欧字併記」を求めている。
欧字併記が学名として読まれるためには、書体が博物誌の系譜に属している必要がある。
EB Garamond は 16 世紀の活字を復刻した書体で、
リンネ以降の博物誌・図譜の版面と同じ骨格を持つ。

**太字は使っていない。** EB Garamond に Bold は同梱されているが、
本文用の 12pt オプティカルサイズには合わない。
また合成ボールドを踏むと Chromium が Type3 フォントを吐き、
検索性と埋め込み検査の両方を壊す。この点は実際に一度踏んで潰した。

## 出力 PDF に現れるフォント（機械確認の結果）

```
✓ /AAAAAA+EBGaramond-Regular
✓ /BAAAAA+NotoSerifJP-Regular
✓ /CAAAAA+NotoSerifJP-SemiBold
✓ /DAAAAA+NotoSerifJP-Medium
```

- 4 種すべて `/FontFile2` を持つ（サブセット埋め込み済）
- 未埋め込み 0／Type3 0／代替書体（WenQuanYi 等）0
- 抽出可能な文字数 48,066 字
- ToUnicode の異体字寄せ 11 本（詳細は納品書「検索性」の項）

## フォント以外の描画

図版はすべて**フォントを使わないベクター**である。
紋章・主図版・小カット・人物図版・図式・地図のいずれも、
アウトライン化した文字ではなく、はじめから座標で定義された図形として持っている。
地図と図式の中の**注記文字だけ**が Noto Serif JP で、これは検索可能なテキストとして残してある。
