## 0　結論

**ご指摘のとおりです。作り直しました。**

ご提示の相関図が読みやすい理由は、線の引き方ではありません。
**札の中で人物が説明されていること**です。顔・名・肩書の三つが札の中にあるので、
読者は凡例に戻らずに済みます。そのうえで、線には「結婚」「私生児」といった
**語がそのまま刷ってある**。ここでも凡例に戻らずに済みます。

初版の相関図は、この二つをどちらも欠いていました。

## 1　初版が読めなかった理由

四つあります。いずれも「線を減らす」では直りません。

| | 何が起きていたか |
|---|---|
| 一 | **節点が紋章だけだった。** 紋章は二十五ミリで判別できるよう設計した図象で、七ミリでは何の組織か分からない。読者は凡例へ戻る |
| 二 | **関係が線の種類で表されていた。** 実線・二重線・破線・点線の四つを覚えなければ、一本も読めない。ここでも凡例へ戻る |
| 三 | **四十九点を一枚に詰めた。** 円環に並べたので網目にはならなかったが、弦が中央で束になり、どの線がどこへ行くのか追えない |
| 四 | **位置に意味を持たせすぎた。** 分類ごとの扇に固定したため、同じ出来事に関わる組織が円の反対側に離れた。内戦を追う読者は、目を往復させることになる |

四つ目が、いちばん根が深いところです。
**分類は「その組織が何であるか」の区分であって、「何が起きているか」の区分ではありません。**
内戦を追いたい読者にとって、分類 II の頁だけでは足りません。
名家も、教団も、隊商も内戦の中にいるからです。

## 2　改めたこと

### 二-一　節点を「札」にする

```
┌──────────────────────────┐
│ ▌ [紋章]  帝国軍                        │  ← 組織名　3.25mm
│ ▌         帝国の常備軍                  │  ← 肩書　　2.25mm
│ ▌                       ソリチュード    │  ← 所在　　1.95mm
└──────────────────────────┘
```

紋章・組織名・肩書・所在の四つを札の中に入れました。
左端の色帯が分類を示します（前付「分類について」と同じ色）。

**肩書は四十九項ぶんを書き下ろしました。**「傭兵団」「窃盗組織」「九領の合議」など、
八字以内で、その組織が何者かが一目で分かる語を選んでいます。

### 二-二　線に語を刷る

線の中央に白い小札を置き、**敵対・同盟・従属・派生・反目**をそのまま刷ります。
線の種類（太さ・破線）も残していますが、これは補助です。語だけで読めます。

**凡例は一枚ごとに刷ります。** 巻頭に一度だけ載せる方式は、
途中の頁を開いた読者に届きません。

### 二-三　一枚あたり七〜十枚に絞る

頁数の制約を外していただいたので、**十九枚に分けました。**

| | 枚数 | 内容 |
|---|---|---|
| **主題別** | 8 | 内戦／信仰の禁圧／竜の帰還／血と呪い／盗みと負債／記録と知／容認されざる祭祀／辺境と部族 |
| **分類別** | 11 | 七分類。相手の多い分類は割った（I・III が二枚、II が三枚） |

### 二-四　主題別の図を立てる

分類ではなく、**何が起きているか**で束ねた図です。
たとえば「血と呪い」の一枚には、同胞団・グレンモリルの魔女・シルバーハンド・
シルバー・ブラッド家が並びます。分類は I・VI・III・IV とばらばらですが、
**与える者・負う者・狩る者・銀を売る者**が一本の線でつながっているのが見えます。

八枚の**札の位置は、一枚ずつ手で決めています。**
力学的な自動配置を使わないのは、交差の無い配置を機械が見つけられないからです。

## 3　配線の規約

**直交でのみ引きます。** 斜めに引くと、二本が交差したときにどちらがどちらか
分からなくなります。直交なら交差は必ず直角になり、目で追えます。

経路は最大で五点です。

```
札の縁 → 溝の通り道（縦） → 行間の廊下（横） → 溝の通り道（縦） → 札の縁
```

- 隣の列どうしなら通り道は一本で済み、三点に縮みます
- 同じ行で、あいだが空いていれば、折らずにまっすぐ引きます
- 通り道と廊下は、**区間の重なる線どうしで必ず別のものを割り当てます**

札の縁の出入口も割り当て制です。一枚の札から何本も出るとき、
すべてを中心から出すと線が重なります。縁の高さを本数で割り、
相手の上下の順に並べて配ります。

**辺を多く持つ札は、背を二行分にします。** 帝国軍のように十三本を持つ札を
高さ十三ミリの縁から出すと、出入口の間隔が一ミリを切り、どれがどれか分からなくなります。

## 4　機械で検めたこと

`node src/proof-relmap.mjs` を走らせると、目では拾えない三つを機械が出します。

| 検め | 何を見るか |
|---|---|
| **線が札の下を通っていないか** | 通ると、その線がどこへ繋がるのか追えなくなる |
| **語どうしが重なっていないか** | 二枚が重なると、どちらも読めない |
| **語が組織の札に掛かっていないか** | 掛かると、組織名か関係語のどちらかが潰れる |

```
19 枚中 すべて 可
```

語の置き場は、経路のうち**どの札にも掛からない区間**から選びます。
「いちばん長い線分の真ん中」では足りません。長い線分でも、端が札に接していれば
語が札に乗るからです。

高さを取るか、札を小さくするか、二つの案があります。ご指示をいただければ着手します。
