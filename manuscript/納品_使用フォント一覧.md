| 配布元 | https://github.com/fontdasu/ShipporiMincho ／ Google Fonts |
| ライセンス | SIL OFL 1.1 |

採用理由は本文書末尾の「4-3 への回答」に記す。要点だけ言えば、
この書体は活版の刷り上がりを起点に設計されており、**字面に既に湿りがある**。
清潔すぎる明朝を後処理で汚すより、はじめから濁っている書体を選ぶほうが早く、確かだった。

**手書き風書体は本文には使っていない**（仕様 4-3 (c) を避けるという判断）。

既製の手書き風書体でも嘘にならない。

## 補遺（後年の刷り物）用

写本本体とは**別の紙・別の版**であることを示すため、意図的に和文ゴシック＋ラテンで組んでいる。

### Noto Sans JP

| | |
|---|---|
| 使用ウェイト | Regular 400 / Bold 700（可変フォントから静的インスタンスを切り出し） |
| 用途 | 補遺の本文・見出し・表 |
| 権利表示 | Copyright 2014-2021 Adobe, with Reserved Font Name 'Source' |
| ライセンス | SIL OFL 1.1 |

配布物は可変フォント（`NotoSansJP[wght].ttf`）だが、可変フォントのまま組むと
Chromium が PDF 化の際に**字ごとの Type3 フォントに分解**してしまい、
埋め込み要件と検索性の両方を損なう。`fontTools.varLib.instancer` で
400 と 700 を静的に切り出し、name テーブルを整えたうえで使用している。

## 埋め込み状況（PDF 実測）

```
✓ ShipporiMincho-Regular      ✓ ShipporiMinchoB1-Regular
✓ ShipporiMincho-Medium       ✓ ShipporiMinchoB1-Bold
✓ ShipporiMincho-SemiBold     ✓ ShipporiMinchoB1-ExtraBold
✓ ShipporiMincho-Bold         ✓ KleeOne-Regular
✓ NotoSansJP-Regular          ✓ NotoSansJP-Bold
✓ EBGaramond-Regular
```

11 種すべて埋め込み済。Type3 への分解なし。系統外の書体への代替なし。
`python3 src/finish.py screen` で毎回自動検品している。

## 候補にしたが採らなかったもの

| 書体 | 採らなかった理由 |
|---|---|
| A1明朝 | 有償。にじみの表現は理想的だが、本件の後処理で同等以上を作れると判断した |
| 筑紫明朝 | 有償。字面が整いすぎており、旅の途上の記録にはやや上品 |
| 貂明朝 | Adobe Fonts 経由の提供で、PDF 埋め込みの権利関係が納品物として不透明 |
| 游明朝 | OS 同梱版と製品版で字形が異なり、再現性が担保できない |
| 手書き風和文書体全般 | **仕様 4-3 (c) に対する当方の見解のとおり、本文には使用しない** |
